# Nawex

## Agent-powered Business Network

Nawex connects buyers, suppliers, service providers and advertisers through intelligent agents.

The agent can:

- understand demand
- discover supply
- match buyers and sellers
- compare offers
- coordinate negotiations
- create orders
- coordinate fulfillment
- manage marketing workflows

## Initial MVP

- Buyer requests
- Supplier catalog
- Service catalog
- Matching engine
- Offers
- Orders
- Commission tracking
- Marketing campaigns
- Agent task registry

## Business model

Nawex earns from transactions and services performed through the network.

## Important

Payment and external provider integrations are isolated behind provider adapters.

Do not put production secrets in the repository.
